# thesis1

Mã MATLAB trong thư mục `/source_code - v1` đã được chuyển sang Python với các file `.py` tương ứng.

## Chạy bản Python

Ví dụ:

```bash
cd "/home/runner/work/thesis1/thesis1/source_code - v1"
python RUN_MONTE_numBeams.py
python RUN_MONTE_numUE.py
python RUN_MONTE_executive_time.py
```

Bản hội tụ:

```bash
cd "/home/runner/work/thesis1/thesis1/source_code - v1/Test_convergence"
python RUN.py
```
